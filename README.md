# SentinelTrade — Plataforma de Trade Financeiro de Alta Criticidade

O **SentinelTrade** é uma plataforma distribuída, segura, escalável e tolerante a falhas voltada para o mercado de capitais simulado, operando com ações, ETFs e fundos imobiliários para a corretora fictícia **Orion Capital**.

Sendo um sistema financeiro de **alta criticidade**, o projeto foi desenvolvido com foco em segurança, rastreabilidade, resiliência arquitetural e validação de risco em tempo real.

Projeto prático integrador desenvolvido para a disciplina de **Projeto de Software** na **Universidade Presbiteriana Mackenzie** (Faculdade de Computação e Informática - FCI).

## Tecnologias Utilizadas

### Linguagens & Runtimes
* **Linguagem / Runtime:** Java 17+ (ou Python 3.11+ / C# .NET 8 / Node.js) *(Ajuste conforme a linguagem do grupo)*

### Frameworks & Bibliotecas
* **Framework Principal:** Spring Boot / FastAPI / .NET Web API
* **Segurança & Autenticação:** Spring Security / JWT / MFA (Multi-Factor Authentication)

### Banco de Dados & Armazenamento
* **Banco de Dados Relacional:** PostgreSQL / MySQL
* **Cache em Memória:** Redis (para controle de sessão e cotações)

### Ferramentas de Modelagem & Engenharia de Software
* **Modelagem UML:** Astah / Enterprise Architect / Mermaid.js
* **Versionamento:** Git & GitHub
